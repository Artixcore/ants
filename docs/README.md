# Ants Documentation

This directory will contain the project's technical specifications.

Planned documents:

- `architecture.md`: system boundaries, components, and data flow;
- `agents.md`: responsibilities, permissions, and communication contracts;
- `mission.md`: mission schema, budgets, stop conditions, and lifecycle;
- `evidence.md`: evidence, hypotheses, provenance, confidence, and contradiction handling;
- `security.md`: threat model, sandboxing, secrets, and approval controls;
- `providers.md`: model and cloud-provider adapter contracts.

Documentation should describe implemented behavior precisely. Proposed behavior must be clearly labeled as planned or experimental.
